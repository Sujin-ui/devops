### 셸 스크립트 
- 여려명령을 파일에 작성
- 실행권한, shebang 을 확인후 작업 경로 설정
- 환경변수로 프로그램의 실행설정에 전달 
- 명령 종료 상태로 성공과 실패 판단 가능 
- 표준 출력, 오류,실패 종료 등을 구분합니다 

#### 분석 명령  
- 0 => True
- 1 => False

- || => OR 
- !  => NOT 

		2번 구역  1번구역 
if ! command -v python3 > /dev/null 2>&1; then 
- 2>&1 
	- 2번표준 오류를 1번 표준 출력이 가는곳으로 보냄 
	- 즉 2번 오류를 1번으로 이동 

- 0 : 표준 입력 
- 1 : 표준 출력 
- 2 : 표준 오류
