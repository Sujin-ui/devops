# 2주차 내용 정리 

### 가상화 
- 가상화 
	- 서버에 적용되는 기술 
	- 물리적 환경내에 여러개의 논리적인 컴퓨팅 환경
- 베어메탈 방법 
	- PC 한대에 OS 설치후 여러소프트웨어 운영 
		- 장점 : 하나의 OS에서 모든 프로그램 관리 쉬움 
		- 단점 : 프로그램 하나가 해킹 -> 다른정보도 위험 
- 하이퍼바이저 
	- PC 한대에 여러 가상 머신
	- 즉 : 물리 하드웨어를 공유할 수 있도록 리소스를 가상화 하고 관리 함 
- 컨테이너 
	- 하이퍼 가상화 보다 가볍고 빠르다 
	- 격리된 공간을 만들 수 있음 
		- 모든 컨테이너가 호스트 OS 커널을 공유

### WSL 
- 장점
	- 빠른속도 : 가상머신보다 적은 리소스 
	- 시스템 통합 : 파일 탐색기에서 쉽게 접근 
	- 편리한 개발 : Bash 명령어를 그대로 사용 
- Ubuntu 
	- 공동체 속에서 함께 살아가는 존재 

#### 리눅스 명령어 
- mkdir <디렉터리 이름 > # 파일 만들기 
- cd <디렉터리 이름 > # 디렉터리 이동 
- pwd #현재 디렉터리 확인 
- ls #파일/폴더 목록 확인 
- touch <파일 이름 > #빈 파일 생성 후 확인 
- rm <파일 이름 > #삭제 

- echo "내용"> 패키지 이름 
- cat 패키지 이름 

- sudo apt update # 패키지 목록 최신 상태 갱신 
- sudo apt install <패키지 이름> # 패키지 설치 
- sudo apt remove <패키지 이름> # 패키지 삭제 

#### 깃 명령어 
- git init # 디렉토리 초기화 
- git status # 깃 상태 확인 
- git add <파일 이름 > #준비 단계 업로드 
- git commit -m "메세지 " #커밋 하기 
- git log #로그 내역 확인 

- 브랜치 만들기 
- git switch -c <브랜치 이름> # 브랜치 만들기 
- git switch branch # 브랜치 만들기 
- git branch #현재 브랜치 확인 
- git push # 원격 깃허브에
