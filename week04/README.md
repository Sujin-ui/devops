# 4주차 수업 내용 
## 자동화 
- 자동화란? 
	- 디렉터리와 경로를 이해하고 find,grep,파이프로 필요한 정보 찾기 
	- 변수 인자 조건 반복을 이용 
- 디렉터리
```
	├── home/ 	사용자 작업공간 
	├── etc/ 	시스템과 프로그램 설정 
	├── var/log/    시스템과 서비스 로그가 주로 저장 위치 
	├── tmp/ 	임시 파일 
	 ── usr/bin/ 	주요 실행 파일 명령어
```
- 경로
	- 현재 위치 . 
	- 상위 위치 ..
	- 홈 	     ~
	- 루트 	     /
- 조건문과 파일 검사 
	- 단항 연산자 [ 연산자 값 ] 
	- -f 파일 : 파일 존재 유무 
	- -d 폴더 : 폴더 존재 유무 
	- -z 문자열 : 문자열 길이 = 0
	- -n 문자열 : 문자열 길이 != 0 
	- 이항 연산자 [값1 연산자 값2]
	- -eq : 정수가 같은지 
	- -ne : 정수가 다른지 
	- -gt : 정수가 큰지 
	- -lt : 정수가 작은지 
	- -ge : 정수가 크거나 같은지 
	- -le : 정수가 작거나 같은지 
## 프로세스 백업 
- ps aux : 시스템 실행중 모든 프로세스 상세히 보여주기 
- aux : a (모든 사용자) u (사용자 중심 상세) x (터미널에 연결되지 않은 프로세스 포함 백그라운드등)
- tar : 여러 파일을 하나 아카이브로 묶는 도구 
	- -tzf : 내용 확인 
	- -xzf : 압축해제 
	- -czf : 압축생성 
	- -C   : Cjange directory (작업할 디렉터리 지정)
- diff -rq 
	- 다르면 A and B differ 표시 
		- echo $?시, 1출력(0같음,1다름,2오류)
- gitignore 
	- 지정한 파일을 새로 GIT 추적대상에 불포함 

## 협업 
- 협업
	- .gitignore로 관리하지 않을 결과물 제외
	- 브랜치 -> 커밋/푸시 -> PR -> Merge
	- conflict 발생 -> 로컬 해결 -> Commit/push -> PR Marge 
### GIT 브랜치 
```git branch # 현재 브렌치 확인 
git switch -c (브랜치 이름) #브랜치 생성 및 변경```
#### Pull requests 
```gh pr create --title "내용" \ --body "내용" #Pr 생성 
git pr merge --squash --delete-branch #main에 합치며 삭제```
 

## 네트워크 
- 127.0.0.1 => localhost 
- 0.0.0.0 => 모든 네트워크 인터페이스에 연결 받음 
- IP 주소 : 네이퉈크에서 장치 식별주소 
	- 공인 IP : 전체에 유일한것 
	- 사설 IP : 해당 사설 네트워크 내부에 사용주소 (학교, 집 등등)
- 포트 : 컴퓨터 안에 실행중 서비스 구분 번호 
	- 22   : SSH <서버원격 접속>
	- 80   : HHTTP <웹>
	- 443  : HTTPS <보안웹>
	- 3306 : MySQL
	- 6379 : Redis
	- 8080 : 개발용 웹서버 

- DNS  : 도메인 이름을 IP주소로 변환 

	- ip addr(IP), ping(응답 확인), dig(DNS),curl(HTTP),ss(LISTEN 포트)

- 서버는 특정 초트에 요청을 기다리며 이미 사용중인 포트 재사용시 충돌 발생 우려 

- 방화벽 
	- 서버를 열어도 방화벽에서 차단시 외부 접근 불가능
